# GEN-AI Chatbot

A simple AI chatbot built using **Streamlit**, **LangChain**, and **Mistral AI**. The chatbot provides an interactive chat interface where users can communicate with a Mistral language model in real time.

## Features

* Interactive chat interface
* Powered by Mistral AI
* Built with Streamlit
* Maintains conversation history during the session
* Easy to set up and run locally

## Technologies Used

* Python
* Streamlit
* LangChain
* Mistral AI
* python-dotenv

## Installation

Clone the repository:

```bash
git clone https://github.com/ashwinkubade/GEN-AI-Chatbot-model-.git
cd GEN-AI-Chatbot-model-
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file and add your Mistral API key:

```env
MISTRAL_API_KEY=your_api_key_here
```

Run the application:

```bash
streamlit run UIchatbot.py
```
